# BeatPad

A dead-simple beat maker for Android. 6 drum sounds, 16-step grid, BPM slider. Tap cells to toggle, drag to paint, tap a track name to preview.

## Get the APK
Go to the **Releases** page → `latest` → download `BeatPad.apk`. Install on your phone (allow installs from unknown sources when asked).

Every push to `main` rebuilds the APK automatically via GitHub Actions.
